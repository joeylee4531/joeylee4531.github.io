# Nero Security Blog

Jekyll 기반 보안·개발 블로그입니다.

Ruby와 Bundler 설치 후 `bundle install`, `bundle exec jekyll serve`로 실행합니다.

`_pages/Category A/` 아래 카테고리 폴더에 Markdown 글을 추가하고 title, date, tags를 지정합니다. 일반 안내 페이지는 `page_type: page`를 지정합니다. 연락처는 `_config.yml`에서 관리합니다.
